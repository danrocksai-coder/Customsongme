## 🌟 What is CustomSongMe?
CustomSongMe turns real stories into one-of-a-kind personalized songs. Whether it’s a birthday, wedding, anniversary, love song, memorial tribute, roast, pet anthem, or business jingle — you share the details and Dan the Song Man transforms them into music.

- **Standard Delivery:** Within 24 hours of payment
- **Rush Delivery:** 4-hour rush option available
- **Deliverables:** High-fidelity MP3 + Custom Digital Cover Art + Full Lyrics
- **Features:** Includes *Capture the Moment™* mobile reaction recording directly on customer delivery pages
- **Guarantee:** Personal Happiness Guarantee
---
## 🚀 How It Works
1. **Tell Your Story** Add names, memories, inside jokes, important moments, or your business message.
2. **Complete Payment** Pay securely using Stripe, PayPal, Cash App, Venmo, or Zelle.
3. **Receive Your Song** Your personalized song is delivered via a dedicated, unindexed mobile-friendly page containing the MP3 player, lyrics, custom cover art, and the *Capture the Moment™* interactive video recorder.
---
## 🛠️ Tech Stack & Architecture
- **Frontend:** Pure HTML5, CSS3, JavaScript (ES6+ Mobile-first implementation)
- **Media API:** Native Browser `MediaRecorder` API with multi-codec fallbacks (`video/mp4;codecs=h264,aac`, `video/webm`) optimized for seamless iOS/Safari and Android testing
- **Hosting:** Netlify (Deployed exclusively via mobile workflow)
- **Forms:** Formspree
- **Analytics:** Google Analytics 4
- **SEO:** Optimized `robots.txt`, `sitemap.xml`, canonical URLs, and structured data (JSON-LD)
---
## 📂 Main Project Structure
- `index.html` → Main homepage
- `thanks.html` → Post-submission thank you page
- `sitemap.xml` → Search engine indexing configurations
- `robots.txt` → Crawl instructions preventing indexation of private assets
- `_redirects` → Netlify clean URL rules and redirects
- `_headers` → Custom cache control and security headers
- `logo.png` → Brand logo asset
- `songs/` → Directory housing isolated, client-specific sub-pitch packages (e.g., `/songs/rhonda-derek-a-street-apart/index.html`)
